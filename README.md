A production-grade collection of relational database schemas, advanced analytics, database administration routines, and automated data quality pipelines built for enterprise MySQL 8.0+.

This repository was architected to demonstrate **Senior Database Administrator (DBA)** and **Lead Data Engineer** proficiencies, spanning relational modeling, window functions, hierarchical recursive queries, circular self-joins (Secret Santa logic), transactional safety with savepoints, role-based access control (RBAC), and regular expression text mining.
